# Appomodoro

A Pomodoro timer app with a mechanical dial interface.

## Features

- Mechanical-style dial with rotating number rings
- Continuous 60 fps animation
- Focus, Short Break, Long Break, Custom phases
- Presets: 25/5, 50/10, Custom
- Auto-advance after 4 focus sessions
- Notifications and vibration at phase end
- Settings for accent color, presets, auto-advance, notifications
- State restoration from timestamps

## Build

Run `build_and_verify.bat` to build the app using Gradle wrapper.
